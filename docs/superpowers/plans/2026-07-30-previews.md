# Catalog Previews Implementation Plan (spec C)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every catalog card shows what the item actually looks like — visualizers by running live in the existing sandbox, tiles by a published preview image served from the marketplace.

**Architecture:** Two preview sources behind one fallback rule. Visualizer previews reuse the existing sandbox surface at card size, gated by an `IntersectionObserver` and a hard concurrency cap. Tile previews are uploaded at submission, stored on the bundle row, served from a new endpoint, and fetched **through the Rust client** as size-capped, magic-sniffed bytes turned into a data URL — so the zip-entry allowlist and the page CSP are both untouched.

**Tech Stack:** React 18 + TypeScript (Vite), Rust + Tauri 2, axum + SQLite (server), `node:test` via `tsx --test`, `cargo test`.

## Global Constraints

- The zip-entry allowlist stays exactly `{manifest.json, main.js, preset.json, view.json}`, exact-string matched. **No task may add `preview.png` to it.** Previews are served, never bundled.
- `BROKER_COMMANDS` in `app/src/sandbox/broker.ts` stays `{}`.
- No new CSP origin. Preview bytes come through the Rust client and reach the page as a data URL.
- Preview size cap: **256 KB**. Format accepted on **magic number** (PNG `89 50 4E 47`, JPEG `FF D8 FF`), never on a declared content type.
- Live preview sandboxes: max **6** concurrent, only for cards intersecting the viewport, paused on `hub://window-visibility` hide, no retry after an init failure.
- `useTweaks` is called exactly once, at `App.tsx`; there is no context. Never call it again.
- Item identity is `` `${kind}:${id}` `` everywhere.
- Typecheck with `npx tsc -b` (NOT `--noEmit` — TS6310 against this repo's composite config).
- Baselines: **405 frontend, 63 cargo**. Establish the server crate's baseline in Task 3 before changing it. Each task states its new total.

```ts
// app/src/components/previewSource.ts
// ─────────────────────────────────────────────────────────────────────────────
// Which of the four preview treatments a catalog card gets (spec C §6).
//
// Pure module — no React, no Tauri — so it is node-testable.
//
// Order matters and encodes two safety rules: a live preview RUNS the bundle's
// code, so it is offered only for a visualizer whose code is installed and
// whose manifest validated; and a first-party item is never published, so it
// can never have an image and always takes its glyph.
// ─────────────────────────────────────────────────────────────────────────────
import type { CatalogItem } from '../state/catalog';

export type PreviewSource =
  | { kind: 'live'; bundleId: string }
  | { kind: 'image' }
  | { kind: 'glyph'; glyph: string }
  | { kind: 'placeholder' };

export function previewSourceFor(item: CatalogItem, glyph: string | null): PreviewSource {
  if (item.source === 'first-party') {
    return glyph ? { kind: 'glyph', glyph } : { kind: 'placeholder' };
  }
  if (item.hasPreview) return { kind: 'image' };
  if (
    item.kind === 'visualizer'
    && item.installed
    && item.installedVersion != null
    && item.brokenReason === null
    && !item.removed
  ) {
    return { kind: 'live', bundleId: item.id };
  }
  if (glyph) return { kind: 'glyph', glyph };
  return { kind: 'placeholder' };
}
```

- [ ] **Step 3: Write the implementation**

```rust
pub const PREVIEW_CAP: usize = 262_144; // 256 KiB

/// Identifies an image by its magic number, never by a declared content type —
/// a hostile server controls the header but not the bytes' meaning.
pub fn sniff_image(bytes: &[u8]) -> Option<&'static str> {
    if bytes.len() >= 8 && bytes.starts_with(&[0x89, b'P', b'N', b'G', 0x0D, 0x0A, 0x1A, 0x0A]) {
        return Some("image/png");
    }
    if bytes.len() >= 3 && bytes.starts_with(&[0xFF, 0xD8, 0xFF]) {
        return Some("image/jpeg");
    }
    None
}

/// Fetches a bundle's preview and returns it as a data URL.
///
/// The page has no CSP origin for the marketplace, and deliberately so — an
/// `img-src` grant would let any page-level reference reach the network. The
/// bytes come through this client instead, capped and sniffed, and cross into
/// the renderer already inert.
#[tauri::command]
pub fn marketplace_fetch_preview(
    url: String, id: String, version: String, kind: String,
) -> Result<String, String> {
    if !is_safe_id(&id) {
        return Err("invalid bundle id".into());
    }
    if kind != "tile" && kind != "visualizer" {
        return Err("invalid kind".into());
    }
    let base = url.trim_end_matches('/');
    if !base.starts_with("https://") {
        return Err("marketplace url must be https".into());
    }
    let endpoint = format!("{base}/bundle/{id}/{version}/preview");
    let bytes = get_capped(&endpoint, PREVIEW_CAP)?;
    let mime = sniff_image(&bytes).ok_or("preview is not a PNG or JPEG")?;
    Ok(format!("data:{mime};base64,{}", BASE64.encode(&bytes)))
}
```

Use whatever base64 encoder the crate already depends on; if none, add `base64` to `Cargo.toml`. Reuse `get_capped` — do not write a second fetch helper. Register the command in `lib.rs`'s `invoke_handler`.

```rust
pub async fn preview(
    State(state): State<AppState>,
    Path((id, version)): Path<(String, String)>,
) -> Result<Response, StatusCode> {
    let bytes: Vec<u8> = state.db.lock()
        .query_row(
            "SELECT preview FROM bundles WHERE id = ?1 AND version = ?2 AND status = 'approved' AND preview IS NOT NULL",
            rusqlite::params![id, version],
            |r| r.get(0),
        )
        .map_err(|_| StatusCode::NOT_FOUND)?;
    let mime = sniff_image(&bytes).ok_or(StatusCode::NOT_FOUND)?;
    Ok(([(header::CONTENT_TYPE, mime)], bytes).into_response())
}
```

- [ ] **Step 3: Implement the budget and the preview**

`previewBudget.ts` is a `Set`-backed counter with the cap.

`LivePreview.tsx` renders the existing chromeless sandbox surface (`viz-sandbox-surface.tsx`) at card size, and:
- mounts only when its card intersects the viewport (`IntersectionObserver`, unobserve on unmount);
- acquires a budget slot before mounting and releases on unmount or when it scrolls out;
- renders the fallback when it cannot acquire a slot;
- listens to `hub://window-visibility` and stops the frame feed while hidden, mirroring what the main viz surface already does;
