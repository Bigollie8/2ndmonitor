# Ridgeline

Unknown Pleasures as a live spectrum. Each tick pushes a new mirrored-
spectrum ridge onto the stack and the rest slide down.

## Notes

Rows advance on a fixed ~12Hz cadence, not per frame, so the scroll speed is
the same in every performance mode. Each row is filled opaque before stroking
so nearer ridges occlude farther ones - that occlusion is the whole look.
